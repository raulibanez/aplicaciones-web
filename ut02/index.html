Concepto clave

CSS

Cascading Style Sheets, hojas de estilo en cascada. HTML dice qué es cada cosa; CSS dice cómo se ve.

Para consultar cualquier propiedad: MDN, developer.mozilla.org.

Lenguaje que dice cómo se ve una página HTML: colores, letra, tamaños, espacios y dónde va cada cosa.

Una sola hoja sirve para todas las páginas de la web.

El error más común de la unidad: olvidar el punto y coma o la llave de cierre. Sin punto y coma se pierden esa declaración y la siguiente; sin llave de cierre, todo lo que sigue, y el navegador no avisa. Los comentarios van entre /* y */. Los espacios y saltos de línea son libres. Todo en minúsculas: las propiedades funcionarían en mayúsculas, pero las clases y los nombres de archivo distinguen (.Galeria y .galeria son dos clases). Qué es CSS

Anatomía de una regla

Una hoja de estilo es una lista de reglas. Cada regla dice a qué elementos se aplica y qué aspecto les da.

  • —El selector dice a qué elementos se aplica
  • —Entre llaves, propiedad, dos puntos, valor y punto y coma. Una por línea
  • —Sin el punto y coma o sin la llave de cierre, se pierde lo que viene detrás. El navegador no avisa
style.css
/* Título principal de la página */
h1 {
  color: #041c3f;
  font-size: 2.5rem;
  text-align: center;
}

/* selector { propiedad: valor; } */
p {
  line-height: 1.6;
}

Selectores

Selectores: a quién afecta la regla

El selector elige los elementos. Con estos cuatro tienes casi todo lo que hace falta.

style.css
/* etiqueta: todos los p */
p { line-height: 1.6; }

/* clase: los que llevan class="destacado" */
.destacado { background: #a5e070; }

/* varios a la vez, separados por comas */
h1, h2 { color: #017ce9; }

/* uno dentro de otro (espacio): los a del nav */
nav a { color: white; background: #041c3f; }
  • —La clase se pone en el HTML: <p class="destacado">. Y en el CSS, con un punto delante
  • —nav a llega a los enlaces del menú; el del párrafo se queda como estaba
A también pinta el enlace del párrafo. C busca una clase que no existe: nav es una etiqueta, no una clase. D busca un nav dentro de un enlace, al revés.

px es el píxel CSS, fijo, no el píxel físico de la pantalla. rem viene de «root em»: la letra de :root, lo de la diapositiva de la paleta. rem respeta el tamaño que el usuario haya puesto en el navegador: por eso es la unidad del texto. Demostración de un minuto: abre «Ver ejemplo» (diapositiva de DevTools) y en otra pestaña chrome://settings/appearance, Tamaño de fuente, «Muy grande». 1rem pasa a valer 24 px y la página entera crece; los bordes, en px, se quedan igual. Al acabar, vuelve a «Mediano». Si preguntan por otras: % es del ancho de la caja que lo contiene (el max-width: 100% de las imágenes); vw y vh, del ancho y el alto de la ventana; em es la letra del propio elemento y se acumula. Los decimales llevan punto: 1.5rem, nunca 1,5rem; .5rem es lo mismo que 0.5rem.

Cajas

El modelo de caja

Para el navegador, cada elemento es un rectángulo con cuatro capas, de dentro afuera. Con ellas se calcula cuánto mide una caja y cuánto se separa de las demás.

  • —Contenido: el texto o la imagen. Su tamaño es width y height
  • —Relleno, padding: espacio entre el contenido y el borde. Tiene el mismo color de fondo que el contenido
  • —Borde, border: la línea que rodea la caja
  • —Margen, margin: separación con las cajas de al lado. Transparente

DevTools dibuja esta caja al pasar el ratón por cualquier elemento, con sus medidas.

Figura 2.2. El modelo de caja. Es lo que DevTools enseña abajo del todo en la pestaña Estilos.

border es grosor, estilo y color: solid continuo, dashed a rayas, dotted de puntos. border-radius al 50 % en una caja cuadrada hace un círculo, y a 999px, una píldora (la etiqueta del cuaderno). margin: 0 auto centra una caja que tenga ancho: auto reparte el hueco entre los dos lados. Sombra, si alguien la quiere para la tarjeta: box-shadow: 0 4px 12px gray.

Cajas

Relleno, borde y margen

padding separa el contenido de su borde, border dibuja la línea y margin aparta la caja de las demás.

style.css
.ficha {
  padding: 1rem;
  border: 2px solid #041c3f;
  border-radius: 12px;  /* esquinas redondeadas */
  margin: 1rem 0;       /* arriba y abajo, lados */
}

/* centrar una caja: ancho máximo y margen auto */
.centrada {
  max-width: 15rem;
  margin: 1rem auto;
}
  • —Un valor vale para los cuatro lados. Para un solo lado o para cuatro valores distintos, la siguiente
  • —En tu página: main { max-width: 60rem; margin: 0 auto; }
En las páginas, en los temas de WordPress y en lo que escribe la IA verán las dos formas: lado a lado (margin-top, padding-left, border-bottom) o todo junto (margin: 1rem 2rem). Las dos hacen lo mismo. El orden de los cuatro valores es el de las agujas del reloj, empezando arriba. Con tres valores (poco habitual): arriba, los lados y abajo. border-bottom se usa en la tabla y en la cabecera de la práctica y del examen; border-top, en el pie.

margin, padding y border se escriben lado a lado o todo junto. En las páginas verás las dos formas.

4 left izquierda

Con cuatro valores, este es el orden: empieza arriba y sigue como las agujas del reloj.

/* lado a lado */
.ficha {
  padding-top: 1rem;
  padding-right: 2rem;
  padding-bottom: 1rem;
  padding-left: 2rem;
}

/* todo junto: el mismo relleno */

padding: 1rem 2remArriba y abajo, 1rem; los lados, 2rem

Cinco minutos, primero el profe y luego ellos. Es la ficha técnica de la página de SuperTuxKart, entre dos párrafos. Propuestas: 1) pon margin a 0: la ficha se pega a los párrafos; 2) sube margin-left y margin-right: la ficha se estrecha y se separa de los lados; 3) sube solo padding-left: el texto se aparta del borde izquierdo y el código pasa a cuatro valores; 4) deja arriba y abajo iguales, y los lados iguales: pasa a dos valores; 5) deja solo el borde de abajo: sale border-bottom; 6) cambia la unidad con rem / px: la ficha no se mueve y el código pasa de 1rem a 16px. Por qué el margen y el relleno en rem y el borde en px: los espacios crecen con la letra si el usuario la agranda; el borde es una línea fina y se quiere igual de fina siempre (en rem, 0.125rem vale 2px con la letra normal, pero 3px con la letra muy grande). Funciona de las dos formas: es la costumbre. Con «Ver las capas» se pinta el margen rayado en naranja, el relleno en verde y el contenido en blanco, como el modelo de caja de DevTools. La vista va a 1,5 veces su tamaño real para que se vea desde el fondo de la clase.

Colocar

Colocar cosas: recetas que se copian y se adaptan

El menú en fila o la página en dos columnas no se escriben de memoria. Se copia una receta y se cambian sus valores.

  • —display: flex pone en fila lo que hay dentro: el menú
  • —display: grid hace una rejilla: las columnas y la galería
  • —En cada receta, las líneas marcadas son las que cambias

Figura 2.4. La maqueta final de tu página: grid para las zonas y la galería, flex dentro del menú.

Es el patrón de cualquier web y el que trae el tema de WordPress: nav, ul, li, a. Por qué cada línea, si preguntan: las listas traen viñetas y 40 px de sangría, de ahí list-style: none y padding: 0; display: block en el enlace hace que se pueda pulsar toda la caja. Lo que se cambia: el color de fondo, dónde va la fila (justify-content: flex-start, center o flex-end), el hueco y los colores del :hover. Para quien navega con el teclado, nav a:focus con lo mismo que el hover.

Receta 1

El menú, en fila

El menú de tu página es una lista de enlaces dentro del <nav>. Copia la receta y cambia las líneas marcadas.

style.css
nav { background: #a5e070; }
nav ul {
  display: flex;          /* en fila */
  justify-content: center;
  gap: 0.5rem;
  list-style: none;       /* sin viñetas */
  margin: 0;
  padding: 0;
}
nav a {
  display: block;
  padding: 0.75rem 1.25rem;
  color: #041c3f;
  text-decoration: none;  /* sin subrayado */
}
nav a:hover { background: #041c3f; color: white; }
  • —justify-content decide dónde va la fila: flex-start, center o flex-end
  • —:hover es el enlace con el ratón encima
Lo que se cambia: los colores y el relleno. border-collapse: collapse une los bordes de las celdas en uno; tr:nth-child(even) elige las filas pares (odd, las impares). Si preguntan por los atributos de HTML 4: BORDER es border, CELLSPACING es border-collapse, CELLPADDING es padding y ALIGN es text-align. No cambiar el tamaño de letra en el hover: hace saltar la tabla.

Receta 2

La tabla de la ficha

Relleno en las celdas, una línea fina bajo cada fila y las filas pares de otro color, como una cebra.

style.css
table {
  border-collapse: collapse;  /* bordes unidos */
  width: 100%;
}
th, td {
  text-align: left;
  padding: 0.5rem 0.75rem;
  border-bottom: 1px solid #d6e0ea;
}
th { background: #a5e070; }
/* la cebra: las filas pares */
tr:nth-child(even) { background: #e3ecf3; }
  • —Cambias los colores y el relleno. El resto, igual
Lo que se cambia: el número de columnas (el 2 de repeat), el hueco y el redondeo. 1fr es «una parte» del espacio libre: repeat(3, 1fr) son tres columnas iguales. aspect-ratio con object-fit: cover hace que todas las capturas tengan la misma forma sin deformarse: llenan la caja y se recorta lo que sobra. La destacada lleva la clase en el HTML: <figure class="destacada">. Si preguntan: repeat(auto-fit, minmax(9rem, 1fr)) mete tantas columnas como quepan, sin media query.

Receta 3

La galería de capturas

Una rejilla de columnas iguales y todas las imágenes con la misma forma. En el HTML, tus figuras van dentro de un <div class="galeria">.

style.css
.galeria {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 0.75rem;
}
.galeria img {
  width: 100%;
  aspect-ratio: 16 / 9;  /* la misma forma */
  object-fit: cover;     /* sin deformarse */
  border-radius: 8px;
}
/* una captura que ocupa dos columnas */
.galeria .destacada { grid-column: span 2; }
  • —¿Tres columnas? repeat(3, 1fr)
Se ve el dibujo de la página en el propio CSS: cambiar la maqueta es cambiar las comillas. Lo que se cambia: el ancho de las columnas (2fr 1fr: el main, el doble que el aside; 3fr 1fr, el triple) y el hueco. Cada zona va a su área con grid-area; esas cinco líneas no cambian nunca. En el móvil la página tiene que ir en una columna: es la receta siguiente.

Receta 4

La página en dos columnas

Con grid-template-areas dibujas la maqueta con palabras: cada fila entre comillas y cada zona con su nombre.

style.css
body {
  display: grid;
  grid-template-areas:
    "header header"
    "nav    nav"
    "main   aside"
    "footer footer";
  grid-template-columns: 2fr 1fr;
  gap: 1rem;
}
header { grid-area: header; }
nav    { grid-area: nav; }
main   { grid-area: main; }
aside  { grid-area: aside; }
footer { grid-area: footer; }
  • —2fr 1fr: el main, el doble de ancho que el aside

Receta 5

El móvil: una columna, y dos en el ordenador

Una media query es un bloque de reglas que solo se aplica a partir de un ancho de pantalla. La base es el móvil.

style.css
/* Base: el móvil. Una columna y el menú apilado */
body {
  display: grid;
  grid-template-areas:
    "header" "nav" "main" "aside" "footer";
}
nav ul { display: flex; flex-direction: column; }
/* Desde 48rem: dos columnas y el menú en fila */
@media (min-width: 48rem) {
  body {
    grid-template-areas: "header header" "nav nav"
                         "main aside" "footer footer";
    grid-template-columns: 2fr 1fr;
  }
  nav ul { flex-direction: row; }
}
  • —48rem son 768 px: a partir de ahí, la maqueta del ordenador
  • —Compruébalo con el modo dispositivo de DevTools

Unidad 2

Resumen de la unidad

01

CSS dice cómo se ve una página. Va en una hoja aparte, style.css, enlazada con <link>.

02

Una regla es selector, propiedad y valor. El selector elige: una etiqueta, una clase, varias o una dentro de otra.

03

DevTools enseña qué regla pinta cada cosa y deja probar el cambio. Lo tachado es lo que perdió.

04

La paleta en :root, la letra y los espacios en rem (1rem = 16 px), y cada caja con relleno, borde y margen.

05

Para colocar, una receta: flex pone el menú en fila y grid hace las columnas y la galería. Se copia y se cambian sus valores.

06

La media query da otra maqueta al móvil, y el modo dispositivo de DevTools la comprueba.

Chuleta de estudio, 1 de 2. Cómo se escribe y se enlaza el CSS, los selectores, los colores con la paleta, la letra, las medidas y quién gana. Cada encabezado de color salta a la diapositiva que lo explica. Modo repaso difumina las explicaciones de las dos chuletas: el alumno dice qué hace cada línea y pasa el ratón (o pulsa la fila) para comprobarlo. Se imprimen con Ctrl+P.
