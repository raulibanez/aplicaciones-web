Qué es CSS

Un poco de historia, sin versiones que memorizar

CSS lo mantiene el W3C, la organización que publica los estándares de la web. La referencia que usaremos es MDN; para saber si algo funciona en todos los navegadores, caniuse.com o la marca «Baseline» de MDN, que aparece cuando algo ya funciona en todos.

«CSS3» es el nombre que muchos tutoriales dan a todo lo que llegó después de CSS2: una etiqueta, no una versión. Todo lo de esta unidad funciona en cualquier navegador actual.

  2. 1996CSS1: texto, colores, fondos, márgenes
  3. 1998CSS2: posicionamiento y cajas. Muchos tutoriales antiguos se quedan aquí

Qué es CSS

Anatomía de una regla

Una hoja de estilo es una lista de reglas. Cada regla dice a qué elementos se aplica y qué aspecto les da.

  • —El selector dice a qué elementos se aplica la regla
  • —Entre llaves, las declaraciones: propiedad, dos puntos, valor y punto y coma. Una por línea
  • —Los comentarios van entre /* */
  • —Espacios y saltos de línea libres, para que se lea bien. Todo en minúsculas: las clases distinguen .Galeria de .galeria
  • —Sin punto y coma se pierden esa declaración y la siguiente; sin la llave de cierre, todo lo que viene detrás. El navegador no avisa: descarta lo que no entiende
estilos.css
/* Título principal de la página */
h1 {
  color: #041c3f;
  font-size: 2.5rem;
  text-align: center;
}

/* selector { propiedad: valor; } */
p {
  line-height: 1.6;
}
Primero la hoja externa, que es la que se usa. El atributo style en línea es lo que hacían FONT y ALIGN en HTML 4: mezcla contenido y aspecto y hay que repetirlo en cada etiqueta. Ni type=text/css ni rel=STYLESHEET en mayúsculas: son restos de HTML 4.

Qué es CSS

Tres formas de aplicar CSS, y la que usamos

El CSS puede ir en un archivo aparte, dentro del <head> o en la propia etiqueta. Las tres funcionan; usamos el archivo aparte porque un solo cambio llega a todas las páginas del sitio.

1 · Hoja externa: la que usamos

index.html
<head>
  <meta charset="utf-8">
  <title>SuperTuxKart</title>
  <link rel="stylesheet"
        href="estilos.css">
</head>
estilos.css
h1 { color: crimson; }

Un archivo para todo el sitio. Se cambia una vez y cambian todas las páginas.

2 · Interna: para pruebas y CodePen

index.html
<head>
  <meta charset="utf-8">
  <title>SuperTuxKart</title>
  <style>
    h1 { color: crimson; }
  </style>
</head>

Vale para una sola página. En CodePen, la pestaña CSS hace esto por ti.

3 · En línea: dentro de la etiqueta

index.html
<body>
  <h1 style="color: crimson;">
    SuperTuxKart
  </h1>
</body>

Mezcla el aspecto con el contenido, hay que repetirlo en cada etiqueta y gana a la hoja, así que luego cuesta cambiarlo. Es lo que hacían FONT y ALIGN en HTML 4: por eso lo evitamos.

Selectores

Selectores básicos: a quién afecta la regla

El selector es la parte de la regla que dice a qué elementos se aplica. Estos son los cinco básicos: por etiqueta, por clase, por id, varios a la vez y todos.

estilos.css
/* de elemento: todos los p */
p { line-height: 1.6; }

/* de clase: los que llevan class="destacado" */
.destacado { background: #a5e070; padding: .5rem; }

/* de id: el único elemento con id="ficha" */
#ficha { border-left: 6px solid #017ce9; }

/* agrupación: la misma regla para varios */
h1, h2, h3 { color: #041c3f; font-family: sans-serif; }

/* universal: todos los elementos */
* { box-sizing: border-box; }
  • —En el HTML: <p class="destacado"> y <h2 id="ficha">
  • —La clase se repite en todos los elementos que haga falta; el id es único y lo reservamos para las anclas
  • —Nombres que digan qué es, como .precio: si el precio pasa de rojo a azul, el nombre sigue valiendo
Cuanto más concreto, menos cosas alcanza. El descendiente (espacio) es el que más se usa: nav a, .galeria img. El hijo (>) solo baja un nivel: el elemento que está justo dentro. El encadenado (sin espacio) exige las dos clases en el mismo elemento; con espacio sería un descendiente. El de atributo es útil en formularios.

Selectores

Selectores combinados: llegar a un elemento concreto

Los selectores se combinan para llegar solo a los elementos que interesan. Se leen como un árbol familiar: un hijo está justo dentro de otro elemento; un descendiente, dentro a cualquier nivel.

estilos.css
/* descendiente (espacio): los a de dentro del nav */
nav a { color: white; background: #041c3f; }

/* hijo (>): los li que están justo dentro de un ul */
ul > li { margin-bottom: .3rem; }

/* elemento con clase (pegados): solo los p destacados */
p.destacado { font-weight: 700; }

/* dos clases (pegadas): el elemento que tiene las dos */
.boton.grande { font-size: 1.4rem; }

/* de atributo: los input de tipo email */
input[type="email"] { border: 2px solid #017ce9; }
  • —nav a llega a los enlaces del menú; el del párrafo se queda como estaba
  • —Pegados, .boton.grande: un elemento con las dos clases. Con espacio, .boton .grande: un .grande dentro de un .boton
A también pinta el enlace del párrafo. C busca una clase que no existe: nav es una etiqueta, no una clase. D busca un nav dentro de un enlace, al revés.

Colores: cuatro maneras de escribir el mismo

color da color al texto y background, al fondo. El color se escribe de cuatro formas que dan el mismo resultado; la hexadecimal es la más habitual.

estilos.css
/* por su nombre: hay unos 148 */
.nombre { background: crimson; }
/* #rrggbb: rojo, verde y azul, de 00 a ff */
.hex    { background: #dc143c; }
/* abreviado: #fa0 es #ffaa00 */
.hex3   { background: #fa0; }
/* rojo, verde y azul, de 0 a 255 */
.rgb    { background: rgb(220 20 60); }
/* tono (0 a 360), saturación y luz */
.hsl    { background: hsl(348 83% 47%); }
/* transparente: se ve al 40 % */
.alfa   { background: rgb(220 20 60 / 40%); }

/* color, el del texto; background-color, el del fondo */
body { color: #041c3f; background-color: #fefefe; }
  • —hsl elige el tono en la rueda de color, de 0 a 360: para aclarar u oscurecer, basta cambiar el último número. Con comas, rgb(220, 20, 60), también vale

Tipografía

Con estas propiedades se eligen la letra, su tamaño, su grosor y el espacio entre líneas. font-family recibe una lista de fuentes, la pila: el navegador usa la primera que tenga instalada.

estilos.css

  font-size: 1.1rem;
  line-height: 1.6;  /* interlineado: 1,6 × la letra */
}
h1 {
  font-size: 2.5rem;
  font-weight: 800;  /* grosor: 400 normal, 700 negrita */
  letter-spacing: -.02em;  /* espacio entre letras */
  text-align: center;  /* lo que hacía P ALIGN */
}
h2 { font-style: italic; text-transform: uppercase; }
a  { text-decoration: none; }   /* sin subrayado */

Cajas

Todo es una caja

Para el navegador, cada elemento es un rectángulo con cuatro capas, de dentro afuera. Con ellas se calcula cuánto mide una caja y cuánto se separa de las demás.

  • —Contenido: el texto o la imagen. Su tamaño es width y height
  • —Relleno, padding: espacio entre el contenido y el borde. Tiene el mismo color de fondo que el contenido
  • —Borde, border: la línea que rodea la caja
  • —Margen, margin: separación con las cajas de al lado. Transparente

DevTools dibuja esta caja al pasar el ratón por cualquier elemento, con sus medidas.

Figura 2.2. El modelo de caja. Es lo que DevTools enseña abajo del todo en la pestaña Estilos.

Atajos: un valor para los cuatro lados; dos valores, arriba-abajo e izquierda-derecha; cuatro valores en el sentido del reloj desde arriba. margin: 0 auto centra una caja que tenga ancho. border es grosor, estilo y color. border-radius al 50 % hace un círculo si la caja es cuadrada. hr: el navegador la dibuja con un borde gris; se cambia con border.

Cajas

margin, padding y border

padding separa el contenido de su borde, border dibuja la línea y margin aparta la caja de las demás. Cada una admite de uno a cuatro valores, uno por lado.

estilos.css
.ficha {

  margin: 1rem 0;            /* dos: arriba-abajo, lados */
  border: 2px solid #041c3f; /* grosor · estilo · color */
  border-radius: 12px;       /* esquinas redondeadas */
  /* sombra: desplazamiento x e y, difuminado, color */
  box-shadow: 0 4px 12px rgb(0 0 0 / 15%);
}
.etiqueta {
  padding: .25rem .75rem;
  border: 2px dashed #017ce9; /* línea a rayas */
  border-radius: 999px;       /* forma de píldora */
}
/* círculo: caja cuadrada con radio del 50 % */

/* hr: sin su borde y con una línea fina arriba */

  • —Cuatro valores van en el sentido del reloj: arriba, derecha, abajo, izquierda
  • —Bordes: solid continuo, dashed a rayas, dotted de puntos. margin: 0 auto centra una caja con ancho: auto reparte el hueco sobrante entre los dos lados
Sin box-sizing, el ancho es solo el contenido: una caja de 250 px con 10 px de borde y 20 de relleno mide 310, y es la causa de muchos desajustes. Con border-box el ancho incluye relleno y borde, y 250 son 250. El alto casi nunca se fija: lo pone el contenido. max-width en vez de width: la caja crece hasta ahí y se encoge en pantallas pequeñas. El reset abre todas las hojas del curso.

Cajas

Ancho, alto y el reset del curso

Cada navegador trae márgenes y medidas por defecto que descuadran las cajas. El reset son tres reglas que lo igualan y abren todas las hojas del curso. El ancho se limita con max-width.

estilos.css
/* El reset del curso, al principio de la hoja */
/* el ancho incluye el relleno y el borde */
* { box-sizing: border-box; }
/* el body, pegado a los bordes de la ventana */
body { margin: 0; }
/* cada imagen cabe en su caja */
img { max-width: 100%; height: auto; }

/* Ancho máximo: crece hasta 60rem y se centra */
main { max-width: 60rem; margin: 0 auto; }

/* Las dos cajas: width: 250px, padding: 20px y
   borde de 10px. Solo una mide 250 en total */
.sin { box-sizing: content-box; }
.con { box-sizing: border-box; }
  • —El alto lo pone el contenido, y así el texto siempre cabe. Para asegurar un mínimo, min-height
  • —Con max-width la caja se encoge sola en pantallas estrechas. Es el primer paso del diseño responsive
La puntuación 1, 10, 100 sirve para comparar, pero no se suma: once clases no ganan a un id. La hoja interna y la externa tienen la misma fuerza; decide el orden en el head. !important gana a todo y por eso no se usa: se convierte en el problema que había que resolver. Cascada

Cascada, especificidad y herencia: quién gana

Cuando dos reglas dan valores distintos a la misma propiedad de un elemento, el navegador aplica uno. Estas cuatro reglas deciden cuál gana: en DevTools, lo que pierde sale tachado.

1

Gana la regla más específica, la que señala el elemento con más precisión. Un id pesa más que una clase; una clase, más que un elemento. nav a gana a a. Se puede contar 100 por id, 10 por clase y 1 por elemento, pero once clases no ganan a un id.

2

A igual especificidad, gana la última escrita. Por eso el orden de la hoja importa, y la interna y la externa tienen la misma fuerza: decide cuál va después en el <head>.

3

El estilo en línea gana a la hoja, y !important gana a todo. Por eso los evitamos: para corregir esa regla haría falta otro !important.

4

Herencia. Lo del texto (color, fuente, tamaño) pasa de body a todo lo de dentro; la caja (borde, margen, fondo) es propia de cada elemento. Por eso body { font-family } cambia toda la página.

Colocar cosas

Cajas de bloque y cajas de línea

Cada elemento se coloca según su display: en bloque, uno debajo de otro como los párrafos, o en línea, seguido del texto como un enlace.

  • —display: block: ocupa toda la anchura y empieza en línea nueva. p, h1, div, section
  • —inline: sigue la línea del texto y mide lo que su contenido; ignora el ancho y el alto. a, strong, span
  • —inline-block: en línea, pero con ancho, alto y relleno. Una etiqueta «PEGI 12»
  • —none: quita el elemento y su hueco. visibility: hidden lo vuelve invisible y conserva el hueco
  • —flex y grid: colocan a los elementos de dentro, los hijos. Vienen a continuación

Sirve para todo lo que va en una línea o una columna: menús, cabecera con logo a un lado y botones al otro, tarjetas en fila, centrar. Flexbox

Flexbox: el contenedor coloca a sus hijos

display: flex va en el contenedor, la caja de fuera, y coloca en fila a sus hijos, los elementos que tiene justo dentro. El contenedor decide la dirección, el reparto y la alineación.

  • —Eje principal: la fila (o la columna). justify-content reparte aquí
  • —Eje cruzado: el perpendicular, vertical si los hijos van en fila. align-items alinea aquí
  • —Para todo lo que va en una dirección: menús, logo a un lado y botones al otro, tarjetas en fila, centrar

Figura 2.5. Contenedor, hijos y los dos ejes. Antes de flexbox (2015) esto se hacía con float y trucos; muchas páginas antiguas siguen así.

Cambiar en DevTools cada valor y ver cómo se recolocan las cajas. space-between es el que más van a usar: logo a la izquierda, menú a la derecha. gap separa sin márgenes.

Flexbox

Dirección, reparto y alineación

Tres propiedades del contenedor deciden en qué dirección van los hijos, cómo se reparte el espacio libre y cómo se alinean; gap pone el hueco entre ellos.

estilos.css
.fila {
  display: flex;
  /* dirección: row, en fila (por defecto), o column */
  flex-direction: row;
  /* reparto en el eje principal: flex-start, center,
     flex-end, space-between, space-around, space-evenly */
  justify-content: space-between;
  /* alineación en el eje cruzado: stretch (estira,
     por defecto), flex-start, center, flex-end */
  align-items: center;
  gap: 1rem;  /* hueco entre los hijos */
}
.columna { flex-direction: column; }
  • —space-between: los extremos, pegados a los bordes, y el espacio libre entre medias: el logo a un lado y el menú al otro
  • —flex-start, center y flex-end juntan los hijos; space-around y space-evenly dejan hueco también en los bordes
Fin del meme de cómo centro un div: flex con justify-content y align-items en center. flex: 1 reparte el espacio a partes iguales; flex: 2 da el doble a uno; flex: 0 0 16rem fija un lateral. flex-wrap deja saltar de línea cuando no caben. Es la maqueta de escritorio de la práctica 2.2, con el cuerpo como contenedor flex que salta de línea; la definitiva, con grid, en la 2.3.

Flexbox

Centrar, crecer y saltar de línea

Tres usos más de flexbox: centrar en las dos direcciones, repartir el espacio entre los hijos y dejar que salten de línea.

estilos.css
/* Centrar en las dos direcciones */
.centro {
  display: flex;
  justify-content: center;   /* en horizontal */
  align-items: center;       /* en vertical */
  height: 6rem;
}

/* El body, contenedor flex que salta de línea */
body { display: flex; flex-wrap: wrap; gap: 0 1rem; }
/* cabecera, menú y pie: la fila entera */
header, nav, footer { flex: 0 0 100%; }
main  { flex: 2; }    /* el doble de espacio… */
aside { flex: 1; }    /* …que el lateral */
  • —flex en un hijo dice cuánto crece: flex: 1 reparte el espacio libre a partes iguales y flex: 2 se lleva el doble. Con 0 0 100%, ni crece ni encoge: ocupa la fila entera
  • —flex-wrap: wrap baja a otra línea los hijos que no caben. Es la maqueta de escritorio de la práctica 2.2; la definitiva, con grid, en la 2.3
Es el patrón que verán en cualquier web y el que trae el tema de WordPress: nav, ul, li, a; la lista sin viñetas ni relleno, en flex; el enlace como bloque para que toda la caja sea clicable. Los enlaces van a las anclas de la página.

Selectores

Estados: cuando pasas el ratón, cuando pulsas

Una seudoclase selecciona un elemento según su estado: con el ratón encima, elegido con el teclado, mientras se pulsa o ya visitado. Así el visitante ve que la página responde.

estilos.css
nav a {
  /* … las reglas del menú, y el cambio suave: */
  transition: background-color .2s, color .2s;
}
/* con el ratón encima */
nav a:hover  { background: #041c3f; color: white; }
/* al llegar con la tecla Tab */
nav a:focus  { outline: 3px solid #017ce9; }
/* mientras se pulsa */
nav a:active { background: #017ce9; }
/* ya visitado: el mismo color que su padre */
a:visited    { color: inherit; }
/* el botón: puntero de mano y crece un 5 % */
.boton { cursor: pointer; transition: transform .1s; }
.boton:hover { transform: scale(1.05); }
  • —Van pegadas al selector, con dos puntos: a:hover. Si usas varias, en el orden link, visited, hover, active: a igual especificidad gana la última, y así cada estado se ve cuando toca
  • —El outline es el contorno que marca dónde está el teclado. Si cambias el del :focus, pon otro: quien navega con Tab lo necesita

Columnas y huecos

    repeat(auto-fit, minmax(9rem, 1fr));

Confusión habitual: absolute no es respecto a la página, ni relative respecto a la caja que lo contiene. absolute sale del flujo y se coloca respecto al ancestro más cercano con position distinto de static; si no hay ninguno, respecto a la página. relative se desplaza desde su sitio y deja el hueco, y sirve sobre todo de referencia. sticky es lo que se usa para el menú.

Posición

position: colocar una caja fuera de su sitio

Las cajas se colocan una tras otra, en el orden del HTML: es el flujo de la página. position saca una caja de ese orden para ponerla encima de otra o dejarla quieta al hacer scroll.

estilos.css
/* static: su sitio en el flujo (por defecto).
   relative: se desplaza desde su sitio y deja el hueco;
   sobre todo, hace de marco para un hijo absolute */
figure { position: relative; width: 16rem; }
.etiqueta {
  position: absolute;  /* encima, respecto a su marco */
  top: .5rem; left: .5rem;
}
/* sticky: normal hasta que llega al borde; ahí se queda */
nav { position: sticky; top: 0; z-index: 10; }
/* fixed: quieta en la ventana, también con el scroll */
.subir { position: fixed; right: .5rem; bottom: .5rem; }
  • —absolute se coloca respecto a la caja con relative más cercana que la contiene; si no hay ninguna, respecto a la página
  • —top, right, bottom y left dicen dónde; z-index, quién queda encima: el número mayor
  • —Dos usos en tu página: la etiqueta sobre una captura y el menú que se queda arriba
B también lo deja fijo, pero desde el principio y tapando lo que hay debajo: hay que compensarlo con un margen. sticky solo actúa cuando el scroll llega a él.

Media queries: la misma hoja, dos maquetas

Una media query es un bloque de reglas que solo se aplica si se cumple una condición, como un ancho mínimo de pantalla. Así una sola hoja da dos maquetas.

estilos.css
/* Base: el móvil. Una columna y el menú apilado */

  display: grid;
  grid-template-areas:
    "header" "nav" "main" "aside" "footer";
}

@media (min-width: 48rem) {
  body {
    grid-template-areas: "header header" "nav nav"
                         "main aside" "footer footer";
    grid-template-columns: 2fr 1fr;
  }
  nav ul { flex-direction: row; }
}

Una hoja crece hasta cientos de líneas. Con un orden fijo encuentras cada regla enseguida, y las media queries, al final, ganan a lo anterior: a igual especificidad gana la última.

Unidad 2

Resumen de la unidad

01

CSS dice cómo se ve. Va en una hoja externa, con reglas de selector, propiedad y valor, enlazada desde el head.

02

El selector elige (elemento, clase, id, descendiente) y la especificidad decide quién gana; el estilo del texto se hereda y la caja es propia de cada elemento.

03

Todo es una caja con relleno, borde y margen; con box-sizing: border-box, el ancho los incluye. rem para texto y espacios, max-width para anchos.

04

Flexbox coloca en una dirección, grid en dos con áreas, y position saca una caja de su sitio: sticky para el menú, absolute para una etiqueta sobre una imagen.

05

Responsive es viewport, unidades relativas, imágenes fluidas y media queries: una hoja, dos maquetas.

06

DevTools enseña cada regla y el validador avisa de los errores. La hoja se organiza en orden: reset, variables, base, zonas, componentes, media queries.
